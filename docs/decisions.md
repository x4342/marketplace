## M14 account rules

The owner replaced the earlier username and password rules. New usernames use 3–20 ASCII letters and digits and are stored in lowercase. Migration 00014 validates new and renamed users while keeping existing names, IDs and uniqueness. Existing names with underscores or more than 20 characters retain authentication and canonical public URLs. New passwords count Unicode code points. Password verification uses the original bytes and existing Argon2id parameters, with no migration of hashes.

M14 moves global keyword search into the shared header. Products remain the default and bare `/discover?q=...` URLs remain valid. Member search uses a bounded canonical username prefix with a C-collation index and filters restricted accounts. Product filter submissions carry the keyword in a hidden field. A deliberate new header search starts a new result set.
